ข่าวประกาศ อัปเดต: — หมวด: ข้อมูล/ไดเรกทอรี

ประกาศการจัดระเบียบ “สารบัญลิงก์ข้อมูล” เพื่อการเข้าถึงที่รวดเร็วและตรวจสอบได้

SaleDatabase Store จัดทำหน้า “ข่าวสารและประกาศ” เพื่อสื่อสารการอัปเดตที่จำเป็นต่อผู้ใช้งาน โดยเน้นความเรียบร้อยแบบเว็บหน่วยงานการศึกษา/รัฐบาล: อ่านง่าย ตรวจสอบได้ และเข้าถึงลิงก์สำคัญได้ทันที ภายในหน้าเดียว

เพื่อความเป็นระบบ เราแยก “ลิงก์ทางลัด” ไว้ด้านซ้าย และรวบรวมรายการทั้งหมดไว้ในส่วน Directory พร้อมแนวทางการอ้างอิงลิงก์ในเนื้อหาให้ดูเป็นธรรมชาติ เช่น Data HK และลิงก์สนับสนุนอื่น ๆ ตามรายการที่กำหนดไว้

  • ลิงก์สำคัญเข้าถึงได้จากเมนูทางลัด (ด้านซ้าย)
  • Directory แสดงลิงก์ทั้งหมดแบบเป็นระเบียบ (ไม่เปลี่ยน/ไม่ลบ)
  • รองรับการวางบน GitHub Pages (ไฟล์เดียวจบ)
หมายเหตุด้านความปลอดภัย

ลิงก์ภายนอกเปิดแท็บใหม่และใช้ rel="noopener noreferrer" เพื่อลดความเสี่ยงด้านความปลอดภัย และคงรูปแบบเดิมตามที่กำหนด

อัปเดตบริการ ประกาศ: — หมวด: การใช้งาน

แนวทางการใช้งานหน้า Portal: ใส่ลิงก์ “แบบมีบริบท” ลดความรก เพิ่มความน่าเชื่อถือ

การใส่ลิงก์จำนวนมากในหน้าเดียว ควรทำอย่างมีรูปแบบ: ให้ Directory เป็น “รายการหลัก” และให้บทความ/ข่าวเป็น “คำอธิบาย” ที่ช่วยผู้ใช้ตัดสินใจว่าควรกดลิงก์ใด ตัวอย่างการอ้างอิงลิงก์ในบทความ: Angkanet เพื่อชี้ไปยังแหล่งข้อมูลที่เกี่ยวข้อง

  • ใช้หัวข้อข่าวสั้น ๆ และระบุหมวดหมู่ให้ชัด
  • ลิงก์ที่ต้องการให้คนคลิกบ่อย ควรวางไว้ “ทางลัด” หรือ “ทางออกหลัก”
  • ลิงก์ทั้งหมดต้องคงเดิมและตรวจสอบได้
